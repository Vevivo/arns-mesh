      Where do I get a connection code?
      Ask an operator running an updated Mesh peer. A code identifies a network and its starting peers. It is reusable and does not grant paid access. An operator's download may already include a network and connect on first start. Otherwise, ask for a connection code.
      If all starting peers are unavailable, ask the operator for a current code. Exported JSON files contain service addresses and public identities trusted for dated name records. They contain no saved pages or private keys.
